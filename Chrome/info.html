Dimomule 1.0

Collega Chrome a eMule per aprire nuovamente i link eD2K, compresi i vecchi link multipli “Aggiungi tutti”.

Cosa fa

Dimomule intercetta i link ed2k:// cliccati nelle pagine web e li consegna al programma che Windows ha associato al protocollo eD2K, normalmente eMule o una sua mod.

Supporta anche i vecchi collegamenti del tipo javascript:addall123456(): quando la pagina contiene un elenco multiplo di link eD2K, Dimomule li recupera e li invia a eMule uno alla volta.

Come funziona

Pagina web→Dimomule→Native Messaging→Windows→eMule

Dimomule non contiene il percorso di eMule. Utilizza l’associazione ed2k:// registrata nel singolo PC: eMule può quindi trovarsi in qualsiasi cartella o disco.

Link supportati

  • link singoli ed2k://;
  • link multipli legacy javascript:addall...();
  • pagine HTTP e HTTPS.

Requisiti

  • Google Chrome su Windows;
  • eMule o mod compatibile;
  • protocollo ed2k:// associato in Windows;
  • Native Host Dimomule installato.

Sicurezza e privacy

  • non invia dati a server esterni;
  • non raccoglie telemetria o cronologia di navigazione;
  • inoltra al componente Windows esclusivamente URL che iniziano con ed2k://;
  • non modifica file di Windows e non usa il file hosts;
  • non modifica l’associazione eD2K, le impostazioni di eMule o i suoi file;
  • la disinstallazione rimuove esclusivamente componenti e registrazioni appartenenti a Dimomule.

Installazione stabile

I componenti installati vengono conservati sotto %LOCALAPPDATA%\Dimomule. Dopo l’installazione la cartella ZIP scaricata può essere cancellata: Chrome deve essere caricato dalla cartella stabile %LOCALAPPDATA%\Dimomule\Chrome.

Gli aggiornamenti vengono distribuiti come pacchetti completi dalla pagina GitHub ufficiale del progetto. L’installer aggiorna i file nella stessa posizione stabile; l’estensione resta la stessa e in Chrome, se necessario, basta premere Ricarica. Non occorre usare di nuovo “Carica estensione non pacchettizzata”.

Guida rapida

  1. Installa Dimomule con INSTALLA_DIMOMULE.cmd.
  2. Carica in Chrome la cartella stabile %LOCALAPPDATA%\Dimomule\Chrome come estensione non pacchettizzata.
  3. Clicca normalmente un link ed2k://: eMule deve riceverlo direttamente.
  4. Per i vecchi pulsanti “Aggiungi tutti”, Dimomule recupera l’elenco e invia i collegamenti a eMule uno alla volta.

Aggiornamenti

Scarica dalla release GitHub più recente il pacchetto completo Dimomule_1.0.zip, estrailo ed esegui INSTALLA_DIMOMULE.cmd. La cartella stabile e l’ID restano invariati. Non devi caricare nuovamente l’estensione: apri chrome://extensions e premi Ricarica soltanto se Chrome non ha ancora recepito i file aggiornati.

Se un link non si apre

Verifica che eMule sia associato al protocollo ed2k://, che Dimomule sia attiva in Chrome e che il Native Host sia installato. Nel pacchetto completo è disponibile anche VERIFICA_DIMOMULE.cmd.
