Dimomule 1.0

Chrome → eMule, senza passaggi manuali sui link eD2K.

Cosa fa

Apre in eMule i link ed2k:// che Chrome moderno blocca e supporta anche i vecchi collegamenti multipli javascript:addall...().

Come funziona

Dimomule intercetta il clic, passa il link al suo Native Host locale e lascia a Windows il compito di aprire il programma associato a ed2k://.

Pagina web → Dimomule → Windows → eMule

Supporto

  • link eD2K singoli;
  • link multipli “Aggiungi tutti”;
  • qualsiasi percorso locale di eMule;
  • Chrome Manifest V3 su Windows.

Sicurezza

Nessuna telemetria. Nessun server esterno. Nessuna modifica al file Windows hosts. Dimomule inoltra al componente locale soltanto URL ed2k://.
