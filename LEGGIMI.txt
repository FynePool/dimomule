DIMOMULE PERSONAL — PACCHETTO COMPLETO
======================================
Build: r001-p1

Dimomule Personal ripristina in Google Chrome per Windows l'apertura dei link ed2k:// in eMule e supporta anche i vecchi link multipli javascript:addall...().
E una versione personale e piu restrittiva derivata da Dimomule 1.0 build r001; ha un'identita propria e puo convivere con l'originale.

PRIMA INSTALLAZIONE
1. Scarica questo repository (Code -> Download ZIP oppure git clone).
2. Estrai completamente lo ZIP in una cartella normale.
3. Esegui INSTALLA_DIMOMULE.cmd.
4. L'installer copia i componenti nella posizione stabile %LOCALAPPDATA%\DimomulePersonal e registra il Native Host. Non apre finestre aggiuntive.
5. Apri chrome://extensions.
6. Attiva "Modalita sviluppatore".
7. Premi "Carica estensione non pacchettizzata".
8. Seleziona %LOCALAPPDATA%\DimomulePersonal\Chrome. Il percorso viene copiato negli appunti dall'installer.
9. Fissa l'icona Dimomule Personal nella barra di Chrome, se desiderato.

IMPORTANTE
Chrome usa direttamente la cartella scelta per un'estensione non pacchettizzata. Per questo devi caricare la copia STABILE in LocalAppData e non la cartella estratta dallo ZIP. Dopo aver completato il caricamento puoi cancellare lo ZIP e la cartella estratta.

AGGIORNAMENTI FUTURI
Dimomule rimane sempre "Dimomule Personal" e mantiene lo stesso ID Chrome. Le revisioni interne vengono indicate come r001-p1, r001-p2 ecc.
Per aggiornare: scarica di nuovo il repository (o esegui git pull) ed esegui INSTALLA_DIMOMULE.cmd. Chrome continua a puntare alla stessa cartella stabile. NON devi premere di nuovo "Carica estensione non pacchettizzata". Se Chrome non recepisce subito i nuovi file, apri chrome://extensions e premi "Ricarica" sulla scheda Dimomule Personal.

SICUREZZA DELL'AGGIORNAMENTO
L'installer prepara la nuova build in staging, esegue un backup dei soli file Dimomule conosciuti e ripristina la situazione precedente se l'aggiornamento non viene completato. Non elimina file estranei eventualmente presenti nelle cartelle Dimomule.

COSA FA
- apre i link ed2k:// usando il programma gia associato da Windows;
- accetta solo link ed2k:// nel formato reale (file, server, serverlist), senza caratteri di controllo o virgolette;
- supporta i vecchi link multipli javascript:addall...(), con richiesta di conferma e al massimo 500 link per volta;
- non contiene un percorso fisso di eMule;
- non raccoglie telemetria;
- non invia cronologia di navigazione a server esterni.

SITI ABILITATI
L'estensione funziona solo su ddunlimited.net, emulelinks.it e ildragonero2.info (e loro sottodomini, HTTP e HTTPS).
Per aggiungere un dominio: modifica le due liste "matches" in Chrome\manifest.json aggiungendo "*://*.nuovodominio.tld/*", riesegui INSTALLA_DIMOMULE.cmd e premi "Ricarica" in chrome://extensions.

PAGINA INFO
Clicca l'icona Dimomule Personal nella barra di Chrome. Si apre il popup informativo. Da li puoi aprire la guida completa interna.

VERIFICA
Esegui VERIFICA_DIMOMULE.cmd per controllare associazione ed2k://, Native Host, registro, identita dell'estensione e popup.

DISINSTALLAZIONE
1. Rimuovi Dimomule Personal da chrome://extensions.
2. Esegui DISINSTALLA_DIMOMULE.cmd.
La disinstallazione rimuove solo la registrazione Native Messaging e i file appartenenti a Dimomule. Non modifica eMule, l'associazione ed2k://, file di Windows o il file hosts.
